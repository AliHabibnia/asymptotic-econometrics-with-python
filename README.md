# Asymptotic Econometrics with Python

**An educational book and computational course on i.i.d. and time-series asymptotics.**

Author and editor: **Ali Habibnia**  
Director, Dataism Laboratory for Quantitative Finance

## Project status

**In development: curriculum stage.** This version contains the revised course structure, editorial workflow, reference guide, and material-status record. Teaching chapters and executable notebooks will be added as they are developed and reviewed.

## Purpose

The project explains how probability limits support econometric estimation and inference. Each unit connects a formal result to its assumptions, a worked mathematical argument, an econometric example, and a reproducible Python experiment where useful.

Independent and dependent observations are both central. Time-series illustrations appear early, and later modules develop the conditions needed for dependent-data limit theorems and inference.

## Reading levels

The foundational treatment presents the intuition, definitions, essential assumptions, and worked examples. The advanced treatment supplies deeper proofs, technical conditions, and extensions. Assumptions needed for a result are stated at both levels.

## Intended readers

Graduate students, researchers, and quantitatively trained practitioners with basic probability, calculus, linear algebra, and regression knowledge. Targeted prerequisite notes will accompany relevant units.

## Publication plan

The first substantive release will contain a complete unit on convergence in probability, its executed notebook, and supporting explanations. It will establish the format for a Quarto web edition and later modules. The roadmap remains provisional while early units are developed.

Questions and feedback will inform revisions, worked examples, and supplementary notes. Material status will distinguish draft, reviewed, and released content. DML is outside the current curriculum.

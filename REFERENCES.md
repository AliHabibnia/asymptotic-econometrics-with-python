## Reading approach

Choose a primary source for each unit and add a complementary source only when it helps resolve a proof, an assumption, or an alternative formulation. The course is not a requirement to read all three books from cover to cover.

Record edition-specific theorem and page pointers when they have actually been checked. Distinguish an adapted proof, an original derivation, and a computational illustration. Do not assign a source's theorem number from memory.

Detailed references will be added with the substantive teaching units. The project will use original prose and computational examples rather than redistribute textbook chapters or exercise collections.
